# Gayathri Sahityam — Interior Designs

> Heritage-Led Luxury Interiors · Rajahmundry · Kakinada · Konaseema

A bespoke, responsive web presence for **Gayathri Sahityam Interior Designs**, an interior architecture studio crafting timeless, deeply personal residences rooted in generational warmth and modern luxury across Coastal Andhra Pradesh.

---

## ✨ Features & Architecture

- **Brand Typography**: Paired with **Cormorant Garamond** (regal, poetic editorial serif) and **Plus Jakarta Sans** (accessible, modern UI sans).
- **Curated Materiality Showcase**: Highlighting Burma Teak, rosewood, Athangudi tiles, hand-cast brass, lime plaster, and cane work.
- **Interactive Dwelling Selector**: Bespoke specifications and layouts for Luxury Villas, Independent Homes, and Apartments.
- **3D Concept vs. Built Reality Slider**: Touch and drag comparison widget demonstrating high-fidelity project execution.
- **Interactive Space Modals**: Detailed architectural breakdowns for modular kitchens, master suites, pooja rooms, and formal living halls.
- **Signature Works**: Case studies from The Godavari Residence (Rajahmundry), Port City Haven (Kakinada), and Ancestral Sanctuary (Konaseema).
- **NRI & Remote Homeowner Guarantee**: Milestones, weekly 4K drone/walkthrough video updates, and WhatsApp site architect integration.
- **Interactive Investment Estimator**: Real-time project cost calculation tailored to dwelling type, sq.ft. area, and finish tiers (Signature Heritage, Modern Classical, Royal Estate).
- **Consultation Dialogs**: Native HTML5 `<dialog>` modal consultation booking with pre-formatted WhatsApp chat links.

## 🚀 Running Locally

You can serve the static site using any local HTTP server:

```bash
# Using Node.js npx serve
npx serve .

# Or using Python 3
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173) in any browser.
